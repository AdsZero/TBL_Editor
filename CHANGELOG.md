# Changelog

Все значимые изменения в этом проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/spec/v2.0.0.html).

## [1.0.0] - 2024

### Добавлено
- ✨ Полная поддержка TBL формата с XOR шифрованием
- ✨ Создание новых TBL файлов
- ✨ Открытие и редактирование существующих файлов
- ✨ Сохранение файлов в формате TBL
- ✨ Импорт из форматов: JSON, YAML, TOML, XML, CSV, INI
- ✨ Экспорт в форматы: JSON, YAML, TOML, XML, CSV, INI
- ✨ Поиск по ID и тексту одновременно
- ✨ Сортировка по ID и тексту (возрастание/убывание)
- ✨ Множественное удаление записей
- ✨ Функционал избранного (добавление в избранное, фильтр по избранному)
- ✨ Темная тема (по умолчанию)
- ✨ Светлая тема
- ✨ Локализация (Русский, English)
- ✨ Адаптивный дизайн
- ✨ Модальное окно для добавления/редактирования записей
- ✨ Валидация уникальности ID
- ✨ Уведомления о действиях
- ✨ Поддержка переменной длины секции Language
- ✨ Автоматический пересчёт смещений при изменении языка
- ✨ Корректная работа с CP1251 кодировкой

### Изменено
- Улучшена производительность рендеринга таблицы
- Оптимизирована работа с большими файлами
- Улучшен UX/UI интерфейс
- Увеличен размер шрифта в таблице для лучшей читаемости
- Увеличены иконки действий для удобства

### Исправлено
- Корректное шифрование/дешифрование при сохранении
- Правильный пересчёт CRSLSectionSize при изменении языка
- Исправлены проблемы с кодировкой CP1251
- Исправлена логика фильтрации и сортировки
- Исправлено обновление избранного при удалении записей

### Техническое
- Полностью написан на TypeScript с строгой типизацией
- Использован React 18 с хуками
- Модульная архитектура компонентов
- CSS переменные для темизации
- Оптимизированы перерендеры с useMemo и useCallback
- Добавлены комментарии к функциям и компонентам
- Создана документация (README.md)
- Добавлен CHANGELOG.md
- Добавлен LICENSE (MIT)
- Добавлен .gitignore

## [0.1.0] - 2024

### Добавлено
- Начальная версия приложения
- Базовая поддержка TBL формата
- Простой интерфейс для редактирования

## Типы изменений

- **Добавлено** - новые функции
- **Изменено** - изменения в существующем функционале
- **Устарело** - функции, которые будут удалены в будущих версиях
- **Удалено** - удалённые функции
- **Исправлено** - исправления ошибок
- **Безопасность** - исправления уязвимостей
