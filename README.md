# TBL Editor

Современное веб-приложение для работы с TBL файлами (бинарный формат с XOR шифрованием).

## 📋 Описание

TBL Editor - это полнофункциональное приложение для создания, редактирования, импорта и экспорта TBL файлов. Поддерживает работу с бинарным форматом с XOR шифрованием, множественные форматы импорта/экспорта, локализацию и темную/светлую тему.

## ✨ Возможности

### Основные функции
- ✅ **Создание** новых TBL файлов
- ✅ **Открытие** существующих TBL файлов
- ✅ **Редактирование** записей (двойной клик или кнопка редактирования)
- ✅ **Удаление** записей (одиночное и множественное)
- ✅ **Сохранение** в формате TBL

### Поиск и сортировка
- 🔍 Поиск по ID и тексту одновременно
- 📊 Сортировка по ID (возрастание/убывание)
- 📊 Сортировка по тексту (возрастание/убывание)

### Избранное
- ⭐ Добавление записей в избранное
- ⭐ Фильтрация только избранных записей
- ⭐ Быстрый доступ к важным записям

### Импорт/Экспорт
Поддерживаемые форматы:
- 📄 **TBL** - нативный формат
- 📄 **JSON** - JavaScript Object Notation
- 📄 **YAML** - YAML Ain't Markup Language
- 📄 **TOML** - Tom's Obvious Minimal Language
- 📄 **XML** - eXtensible Markup Language
- 📄 **CSV** - Comma-Separated Values
- 📄 **INI** - Initialization File

### Интерфейс
- 🌙 Темная тема (по умолчанию)
- ☀️ Светлая тема
- 🌍 Локализация (Русский, English)
- 📱 Адаптивный дизайн
- ⚡ Быстрый и отзывчивый интерфейс

## 🚀 Быстрый старт

### Требования
- Node.js 18+ 
- npm или yarn

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/AdsZero/TBL_Editor.git

# Перейти в директорию проекта
cd tbl-editor

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev
```

### Сборка для продакшена

```bash
# Создать оптимизированную сборку
npm run build

# Предпросмотр продакшен сборки
npm run preview
```

## 📖 Использование

### Создание нового файла
1. Нажмите меню **Файл** → **Создать**
2. Или нажмите кнопку **Создать** на экране приветствия

### Открытие файла
1. Нажмите меню **Файл** → **Открыть**
2. Или нажмите кнопку **Открыть** на экране приветствия
3. Выберите TBL файл

### Редактирование записи
- **Двойной клик** на строке таблицы
- Или нажмите кнопку **редактирования** (карандаш) в столбце "Действия"

### Добавление записи
1. Нажмите кнопку **Добавить**
2. Введите уникальный ID
3. Введите текст
4. Нажмите **Добавить**

### Удаление записей
- **Одиночное удаление**: нажмите кнопку **удаления** (корзина) в строке
- **Множественное удаление**: 
  1. Отметьте строки чекбоксами
  2. Нажмите кнопку **Удалить**

### Избранное
1. Нажмите на **звёздочку** в строке для добавления в избранное
2. Нажмите кнопку **Избранное** для показа только избранных записей
3. Повторное нажатие на кнопку отключает фильтр

### Импорт/Экспорт
1. Нажмите меню **Файл** → **Импорт** или **Экспорт**
2. Выберите формат из подменю
3. Выберите файл (для импорта) или сохраните файл (для экспорта)

### Смена темы
Нажмите на иконку **солнца/луны** в правом верхнем углу

### Смена языка
Выберите язык из выпадающего списка **RU/EN** в правом верхнем углу
